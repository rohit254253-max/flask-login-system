# Flask Authentication System

A secure Flask-based authentication system with user registration, login, logout, session management, and password hashing.

---

## Features

- User Registration
- User Login
- Secure Password Hashing
- Session-Based Authentication
- Protected Dashboard
- Logout Functionality
- Responsive Bootstrap UI
- SQLite Database Integration

---

## Tech Stack

- Python
- Flask
- SQLite3
- Bootstrap 5
- Werkzeug Security

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/flask-login-system.git
```

### Move into Project Folder

```bash
cd flask-login-system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install flask werkzeug
```

### Run Application

```bash
python app.py
```
